# قيد 3.7 — دفتر الذمم

تطبيق أندرويد مستقل بواجهة عربية. بنيت وظائفه بالاستناد إلى الوصف المعلن ولقطات «دفتر الحسابات»، من دون استخدام شفرته أو شعاره أو استيراد بيانات الأشخاص الظاهرة في الصور.

## تثبيت التحديث

- افتح **Qayd-3.7.apk** على أندرويد 7.0 فأحدث مع **Android System WebView** محدث. الحزمة موقّعة بالمفتاح نفسه المستخدم في 3.6 و3.5؛ يمكنك تثبيتها كتحديث دون إلغاء تثبيت النسخة السابقة. يُنصح بحفظ نسخة احتياطية أولًا. إذا طلب النظام السماح بالتثبيت من مصدر التنزيل، اسمح له لهذا المصدر فقط.
- التثبيت الجديد يبدأ بدفتر فارغ. المعاينة في المتصفح تبدأ بأمثلة وهمية ويمكن مسحها من **المزيد ← النسخ والاسترجاع ← بيانات التجربة وإفراغ الدفتر**. إنشاء مسودة رسالة يعمل في التجربة؛ فتح محادثة موجّهة لأرقام التجربة معطّل.
- يحفظ قيد نسخه اليدوية والمجدولة بصيغة **SQLite `.db`** ويظل يقبل نسخ قيد السابقة بصيغتي DB وJSON. نسخة DB التي ينشئها قيد ليست بصيغة الاسترجاع لدى التطبيق السابق. لا تحذف التطبيق السابق أو ملف نسخته أثناء النقل.

## الحسابات أسهل في 3.7

على الهاتف، تظهر الحسابات كبطاقات واضحة فيها الاسم ورقم الهاتف والتصنيف والرصيد، مع زرين مفهومين: **فتح كشف الحساب** و**إضافة حركة**. ابحث بالاسم أو رقم الهاتف؛ الترتيب والتصنيف وحالة الرصيد داخل **تصفية وترتيب**. عند إضافة حساب جديد اكتب الاسم فقط؛ افتح **بيانات إضافية** إذا أردت إدخال الهاتف أو التذكير أو الملاحظات أو تغيير التصنيف. على الشاشة الكبيرة يبقى جدول الحسابات مع فرز الأعمدة. لا تتغير السجلات أو الأرصدة أو طريقة التخزين. راجع [ملاحظات 3.7](RELEASE-3.7.md).

## الواجهة المبسّطة في 3.6

الشريط يعرض **الرئيسية، الحسابات، الحركات، المزيد** فقط. الرئيسية للتسجيل وعرض الأرصدة وآخر الحركات؛ البحث وحساب جديد في **الحسابات**. التحويل وسندات القبض في **الحركات**. انتقلت التقارير والتحصيل وسجل التغييرات وإعدادات الدفتر إلى **المزيد**. في التقارير، استخدم قائمة **نوع التقرير** بدل التبويبات. ظهرت خيارات حفظ النسخ وفحصها واسترجاعها في شاشة واحدة، والتفاصيل الأقل استخدامًا تفتح عند الحاجة. لا تتغير السجلات أو أذونات الفريق. راجع [ملاحظات 3.6](RELEASE-3.6.md).

## مسارا التسجيل ومراجعة تأكيد المشترك (من 3.5)

للقيود الخاصة بهذا الجهاز اختر **تسجيل على الهاتف**، وللقيود التي تريد أن يراها الفريق اختر **تسجيل مشترك**. يُفتح النموذج المشترك بعد الدخول إذا كانت لك الصلاحية، ويبحث بالاسم أو رقم الهاتف داخل الحسابات المسموح بالتسجيل فيها. تظهر الوجهة قبل الحفظ وفي تأكيده. إذا لم يصل تأكيد المشترك، راجع السجل قبل إعادة التسجيل؛ لا يعيد قيد الطلب ولا يجدوله. تعمل التحسينات في التطبيق مع API 3.1 و3.4 دون ترقية الخادم. راجع [دليل 3.5 والتحقق](RELEASE-3.5.md).

## جديد 3.4: نقل تصنيف واستعادة الخادم

من دفتر الهاتف اختر **المزيد ← النسخ والاسترجاع ← نسخ تصنيف أو نقله ← تجهيز ملف نقل مشفّر** لتجهيز ملف تصنيف مشفّر دون رفعه. في **موقع الدفتر المشترك 3.4 ← إعدادات الدفتر ← النقل والاستعادة**، ينزّل المالك نسخة استعادة للحالة الحالية، ثم يراجع تصنيفًا واحدًا ويضيفه كتـصنيف جديد خاص دون استبدال أو منح وصول تلقائي. يشمل ملف استعادة الخادم السجلات وحسابات الفريق وصلاحياتهم. لا يتغيّر الخادم بتثبيت التطبيق؛ تبقى وظائف الدفتر المشترك السابقة متوافقة مع 3.1. راجع [تفاصيل الإصدار والاختبارات](RELEASE-3.4.md).

## ما الجديد في أندرويد 3.3: وضع المدير أو الموظف على هذا الجهاز

في التثبيت الجديد اختر **أنا مدير** لفتح الصفحة الرئيسية ودفتر الهاتف، أو **أنا موظف** لإدخال رابط دفتر المدير وحساب الموظف. في التحديثات، تبقى الصفحة الرئيسية على هذا الجهاز حتى تختار **المزيد ← التفضيلات والأدوات ← وضع هذا الجهاز**. يحفظ قيد رابط الموظف على الهاتف. يمكن للموظف اختيار حفظ دخوله مشفّرًا بعد قبول كلمة السر النهائية وعلى جهاز له قفل شاشة. لا تُحفظ كلمة سر المالك ولا الكلمة المؤقتة.

ما يُسجّل في **الدفتر المشترك** يظهر على أجهزة الفريق وفق التصنيف والصلاحيات. حسابات وحركات دفتر الهاتف لا تُرفع أو تُدمج تلقائيًا؛ المدير يفتح المشترك من زرّه في الرئيسية للعمليات التي يريد مشاركتها. يلزم خادم قيد 3.1 أو أحدث عبر HTTPS؛ لا يتغير الخادم عند تحديث تطبيق الهاتف. راجع [خطوات الإصدار 3.3](RELEASE-3.3.md) و[الإصدار السابق](RELEASE-3.2.md).

## ما الجديد في قيد 3.0

- **الدفتر المشترك ← المزيد ← التحصيل:** فرز الذمم الموجبة حسب الاستحقاق والتصنيف والعملة وتاريخ الرصد، وأعمار التأخر (1–30، 31–60، 61–90، و91 يومًا فأكثر)، وفتح القيود المتبقية، وتسجيل متابعة أو سند قبض مخصّص بإذن مستقل. الإذن بالتقارير لا يتيح التصدير أو كتابة متابعة إلا إذا منح المالك تلك الوظيفة.
- **إعدادات الدفتر المشترك ← أمان حساب المالك:** تحقق اختياري بخطوتين عبر تطبيق مصادقة، وثمانية رموز استرداد أحادية الاستخدام. اتصال HTTPS إلزامي للموقع الحقيقي، وإعادة ضبط الأمان أو كلمة السر تُنهي الجلسات القديمة. راجع [دليل تشغيل الدفتر المشترك](shared/DEPLOY.md) قبل ترقية الخادم.
- **إعدادات الدفتر المشترك ← سجل التدقيق:** تصفية حسب المستخدم أو النوع أو الفترة ومقارنة بيانات القيد قبل التغيير وبعده للعمليات الجديدة. الأحداث السابقة باقية دون إنشاء تفاصيل لم تسجل وقتها.
- **دفتر الهاتف ← المزيد ← النسخ والاسترجاع ← فحص نسخة:** مراجعة DB وJSON الكاملة أو الجزئية والمشفّرة؛ تعرض الحسابات والحركات والسندات والصور والفترة وصافي القيود لكل عملة. يفحص القارئ بنية SQLite والحمولة؛ لا يسترجع بيانات ولا يغيّر ملف النسخة أو كلمة سر الدفتر. يتعرف على ملف الدفتر القديم ويُبيّن أن ترحيله يحتاج مراجعة منفصلة.

## الدفتر المشترك والمستخدمون الفرعيون

الدفتر المشترك خيار منفصل للدخول عبر الإنترنت. يحتاج إلى نشر خادمك على عنوان HTTPS؛ تطبيق أندرويد لا يرفع دفتر الهاتف عند التحديث ولا يزامنه تلقائيًا. يحفظ المدير العنوان من **المزيد ← ربط الدفتر المشترك**. يدخل الموظف من وضع الموظف في التطبيق أو من رابط الدفتر على متصفح جهازه.

بعد دخول المالك إلى الدفتر المشترك في التطبيق اختر **المزيد ← المستخدمون الفرعيون ← فتح مستخدم فرعي**. ما زال الخيار متاحًا أيضًا من موقع الدفتر المشترك. لكل تصنيف اختر العرض أولًا، ثم صلاحيات إضافة الحسابات أو الحركات وتعديلها وحذفها أو عرض التقارير وتنزيل CSV وتسجيل متابعة التحصيل. تتطلب المتابعة والتصدير إذن التقارير للتصنيف نفسه. يُعطى المستخدم رابط الدفتر واسم دخوله وكلمة سر مؤقتة، يغيّرها قبل الوصول. يمكن للمالك تعديل الصلاحيات وإيقاف المستخدم أو إنهاء جلساته. يُنفّذ الخادم الصلاحيات، ولا يكشف طرف تحويل في تصنيف غير مسموح. إدارة المستخدمين والنسخ وسجل التدقيق خاصة بالمالك.

للنشر ونسخ دفتر قيد المحلي إلى دفتر مشترك جديد، اقرأ [دليل تشغيل الدفتر المشترك](shared/DEPLOY.md). يحتوي المصدر على خادم Node.js 24 وSQLite ووصفة Compose مع Caddy. المعاينة التجريبية ببيانات وهمية فقط؛ لا يوجد خادم دائم مُستضاف لدفترك ضمن ملف APK.

## حفظ واسترجاع تصنيف واحد

من **المزيد ← النسخ والاسترجاع ← نسخ تصنيف أو نقله**:

1. اضغط **حفظ نسخة تصنيف** واختر التصنيف المطلوب. يعرض قيد عدد الحسابات والحركات والسندات التي ستدخل النسخة، ويتيح تضمين صور الحركات. احفظ الملف المستقل `qayd-category-….db`. لا يحفظ الملف بيانات بقية التصنيفات أو إعدادات الدفتر أو شعار النشاط أو سجل التغييرات العام، ولا يتغير الدفتر عند أخذ النسخة.
2. اضغط **استرجاع تصنيف فقط** واختر ملف النسخة. إذا اخترت **نسخة قيد كاملة** من هذا المسار، سيطلب قيد تحديد تصنيف منها قبل المراجعة، ولن يعرض استبدال الدفتر الكامل من هذا المسار. أما ملف «دفتر الحسابات» القديم فله مسار الاستيراد الموجّه أدناه.
3. راجع اسم التصنيف المقصود، وعدد الحسابات والحركات التي ستُزال، وصافي الرصيد قبل الاسترجاع وبعده لكل عملة. إن كان التصنيف موجودًا، يمكنك الضغط على **نسخ التصنيف الحالي أولًا**. حدّد مربع الموافقة، ثم اضغط **استرجاع تصنيف فقط**. الاسترجاع **يستبدل هذا التصنيف ولا يدمجه**: تُحذف حساباته وحركاته غير الموجودة في النسخة، دون حذف أو تعديل بقية الحسابات وأرصدتها. إذا لم يكن التصنيف موجودًا، ينشئه قيد. الإلغاء أو الفشل يترك الدفتر كما هو.

**نطاق النسخة:** تشمل الحسابات والحركات الموقّعة بدقة، والسندات وتخصيصاتها، والاستحقاقات والمتابعات والسقوف والإغلاقات المرتبطة بالتصنيف. يحفظ الملف تعريفات العملات اللازمة فقط. عند الاسترجاع تبقى تعريفات العملات الحالية وتسلسل السندات الحالي؛ قد يُضاف تعريف عملة مفقود أو يرتفع آخر رقم سند عند الحاجة. إذا تعارض حساب أو رقم سند مع سجل خارج التصنيف، يتوقف الاسترجاع. تُفسّر القيود المؤرشفة بما يحفظ أرشيف التصنيف دون تغيير إعداد الإغلاق السنوي لبقية الدفتر.

**التحويل بين تصنيفين:** تحفظ النسخة الطرف الخاص بالتصنيف فقط، من دون بيانات الحساب المقابل أو ملاحظة التحويل المشتركة أو صورتها. عند وجود التحويل نفسه في الدفتر المستقبِل مطابقًا، يبقى بطرفيه دون تعديل. إذا لم يوجد، يُسترجع طرف التصنيف كقيد مستقل بإشارته الأصلية، بلا إنشاء طرف مقابل. إذا كان في الدفتر تحويل مشترك يختلف عن النسخة أو سيُمسّ أرشيف طرفه الآخر، يتوقف الاسترجاع ويعرض التعارض بدل تغيير التصنيف الآخر.

**الصور والتشفير:** لا تحوي النسخة الصور إذا ألغيت تضمينها؛ استبدال التصنيف بنسخة بلا صور قد يزيل صوره الحالية. النسخ الجزئية تُشفَّر إذا كان قفل الدفتر مفعّلًا. استخدم كلمة سر النسخة لفتحها، دون تغيير كلمة سر الدفتر المستقبِل. تنفذ العملية محليًا دون اتصال. استخدم **قيد 2.1 أو أحدث** لملفات التصنيفات ولسجلات الاسترجاع. النسخ اليدوية والتلقائية للدفتر الكامل ما زالت منفصلة ومتاحة.

## استيراد نسخة «دفتر الحسابات» القديمة

1. احتفظ بنسخة `.db` الأصلية كما صدّرها التطبيق السابق. افتح في **قيد ← المزيد ← النسخ والاسترجاع ← استرجاع نسخة**، أو اختر الملف من **استيراد من Drive**. لا حاجة إلى رفعه إلى المحادثة أو تغيير امتداده.
2. إذا كان `in` إشارة فقط (`+1` أو `-1`) وكان `out` المقدار، يقارن قيد حصيلة هذه القراءة بأرصدة الملف عند توفر جدول صالح للمقارنة. حين تتطابق القراءة، لا يضيف الإشارة كقيد ثانٍ. إن لم تكفِ الأدلة يطلب تحديد طريقة قراءة العمودين محليًا. في النسخ ذات المبلغين المستقلين، إن ظهرت عينة بمبلغ موجب، قارنها بكشف الحساب في التطبيق السابق وحدد «لي» أو «عليّ». يخص هذا الاختيار المبالغ الموجبة في الملف فقط. **المبلغ السالب يبقى سالبًا** في كشف الحساب وحساب الرصيد؛ مثلًا، يبقى `-35.25` كما هو في أيٍّ من عمودي `in` أو `out`. إذا طُلب تحديد التاريخ أو طرف التحويل، اختر ما يظهر في الكشف الأصلي. لا يُحفظ شيء أثناء المراجعة.
3. طابق رصيد حساب في **العملة نفسها** كما كان وقت أخذ النسخة. إذا احتوت النسخة على صف فيه مبلغان، تعرض المراجعة مثالًا بالقيم الأصلية وأثر كل قيد، وتطلب مطابقة رصيد حساب من الحسابات المعنية. إذا لم يطابق الرصيد كشف التطبيق السابق، فلا تؤكد الاستبدال. لرصيد سالب، أدخل المبلغ بعلامة الناقص مباشرةً، أو أدخل المقدار دون الإشارة واختر «عليّ». يمكنك اختيار **حفظ الحالية أولًا**، والتحقق من اكتمال الحفظ، ثم **استرجاع واستبدال**. يُستبدل دفتر قيد الحالي ولا تُدمج الحركات. قارن بقية الأرصدة قبل الاعتماد على الدفتر الجديد.

إذا كان العمودان يحملان مبالغ مستقلة، فالصف الذي يحتوي على قيمتين غير صفريتين يُنقل إلى **قيدين مستقلين للحساب نفسه وبالعملة والتاريخ والملاحظة نفسها**. لا يُحذف أحد المبلغين حتى إذا كان مجموع أثرهما صفرًا. لا يُنشئ قيد طرف تحويل لهذه الصفوف أو للمبالغ السالبة في الملف أو للسجلات الملتبسة. يجمع طرفي تحويل عادي فقط إذا كان القيدان متطابقين ومتعاكسين بعد تطبيق الإشارات. في صيغة الإشارة والمقدار، يمكن احتساب طرف مفقود عند وجود رابط واحد يدعمه الرصيد وعدد الحركات في كلا الحسابين. تُعزل الحركة بلا مرجع حساب في «حركات بلا حساب (للمراجعة)»، ولا يُنسب قيد لحساب بالتخمين. يحتفظ قيد بثلاث منازل عشرية بدقة، ويرفض القيم التي لا يمكن تمثيلها دون تقريب.

الاستيراد يدعم بنية SQLite ‏`user_version=4` المطابقة للتقرير. ينقل بيانات الحسابات وأرقامها الهاتفية والتصنيفات والعملات وصفوف `transactions` بقيمها وتواريخها وملاحظاتها. لا يقرأ جداول النسخ المكررة أو المحذوفة أو `doc_hdr` كمصدر مالي، حتى لا يتكرر احتساب الحركات. لا ينقل صور التطبيق السابق أو التنبيهات أو التكرار أو إعداداته. عند مبلغ غير قابل للتمثيل بدقة، أو تاريخ غير مقروء، أو حساب/عملة مفقودة بلا مرجع واضح، يتوقف الاستيراد قبل أي تعديل. الحد 48 ميغابايت لملف DB و20 ميغابايت لملف JSON أو حمولة نسخة قيد، و60,000 قيد بعد التحويل. لا تأتي أي قاعدة شخصية ضمن الشفرة أو الحزمة. تنشئ الاختبارات العامة قواعد وهمية لاختبار البنيتين.

## نقل نسخة عبر Google Drive

من **المزيد ← النسخ والاسترجاع ← مشاركة وGoogle Drive**:

- **تصدير إلى Drive:** راجع ما إذا كان الملف مشفّرًا وما إذا كانت الصور مضمنة، ثم اختر **متابعة إلى Drive**. في تطبيق Drive اختر حسابك والمجلد وأكّد الحفظ. إذا لم يُفتح Drive، اختر **حفظ نسخة احتياطية** في قيد ثم ارفع الملف يدويًا. تتضمن أسماء النسخ اليدوية تاريخًا ووقتًا لتفريق الملفات المتتالية.
- **استيراد من Drive:** اختر ملف النسخة `.db` أو نسخة قيد السابقة `.json` من Drive أو منتقي الملفات. إذا لم يظهر Drive في القائمة، افتح الملف من Drive واختر **إرسال نسخة** (وليس **نسخ الرابط**) ثم **استيراد نسخة إلى قيد** إن ظهر. يمكنك أيضًا تنزيل الملف واختيار **استرجاع من الجهاز**.
- **قبل الاسترجاع:** إذا كانت النسخة مشفّرة، أدخل كلمة السر المستخدمة عند إنشائها. بعد ذلك يقارن قيد أعداد الحسابات والحركات والعملات. اختر **حفظ الحالية أولًا** إن أردت نسخة من الدفتر الحالي وتحقّق من نجاح حفظها، ثم أكّد **استرجاع واستبدال**. الاسترجاع يستبدل الدفتر، ولا يدمج الحركات. لن يتغير الدفتر إذا ألغيت أو كان الملف غير صالح.

يُتمّ Drive اختيار الحساب والحفظ؛ قيد لا يطلب كلمة سر Google، ولا يرفع الملفات في الخلفية. في المعاينة في المتصفح، نزّل الملف من Drive أولًا عند الاستيراد، أو نزّل نسخة من قيد وارفعها يدويًا.

## عارض PDF داخل قيد

1. افتح حساب العميل واضغط **خيارات الكشف ← عرض PDF داخل قيد**، أو اختر **المزيد ← التقارير ← خيارات التقرير ← عرض PDF داخل قيد**. يُنشئ قيد ملف A4 من التقرير الحالي ويعرضه داخل التطبيق دون اتصال. يؤثر اختيار الفترة والبحث في الصفوف المصدّرة.
2. مرّر لأعلى وأسفل لقراءة الصفحات. استخدم **+** و**−** أو كبّر بإصبعين؛ اضغط على نسبة التكبير للعودة إلى ملاءمة عرض الصفحة. زر **ملخص التقرير** ينتقل إلى الملخص في آخر المستند.
3. في كشف العميل، **اسحب يمينًا للعملة التالية ويسارًا للسابقة** عند ملاءمة العرض. كل ملف يخص العميل نفسه وبعملة واحدة. أثناء التكبير، يُحرّك السحب الصفحة؛ استخدم زري العملات أو القائمة للتبديل. لا تظهر العملات التي ليس للعميل حركة فيها إلا إن كانت العملة المختارة أصلًا. يبقى نطاق التواريخ والبحث كما هما عند التبديل.
4. استخدم **حفظ PDF** أو **مشاركة PDF** لإرسال أو حفظ المستند المعروض وحده. زر **الطباعة** مستقل، ويتبع خيار «طباعة الكشف بجميع العملات» إن كان مفعّلًا؛ لكل عملة جدول وملخص مستقلان. ملفات PDF المصدّرة غير مشفّرة حتى لو كان الدفتر مقفلًا بكلمة سر. الحد للملف 20 ميغابايت؛ قصّر الفترة إذا تجاوز المستند هذا الحجم.

يظهر **ملخص نهاية التقرير** في الكشف وتقارير الأرصدة والتفاصيل والإجمالي الدوري والتصنيفات، ويبيّن اسم العملة وإجمالي لي وإجمالي عليّ والصافي. في كشف الحساب، يُفصل صافي الحركات عن رصيد البداية والرصيد إلى نهاية الفترة، ويُعرض الرصيد المرحّل منفصلًا عند وجوده. عند البحث، الإجماليات للصفوف المطابقة؛ لا يغيّر البحث رصيد الحساب. التحويل الداخلي لا يدخل في إجماليات الحركات العامة. عند تخصيص تقرير التفاصيل لحساب واحد، يظهر طرفه من التحويل بإشارته الصحيحة.

## مركز التحصيل

افتح **المزيد ← التحصيل**. اختر العملة وتاريخ التقرير (اليوم افتراضيًا). تُقسّم الذمم إلى متأخر، مستحق اليوم، خلال الأيام السبعة المقبلة، مستحق بعد ذلك، وبلا موعد. **المبالغ المستوردة التي ليس لها موعد لا تُسمّى متأخرة.** لا تظهر الأرصدة الصفرية أو التي عليك في قائمة التحصيل.

1. عند إضافة حركة **لي** يمكنك تعيين موعد الاستحقاق المتفق عليه من **تفاصيل إضافية**. للحركات السابقة استخدم **خطة التحصيل ← تحديد الموعد** أو **تفاصيل الحركة ← موعد الاستحقاق**. يمكن ضبط تاريخ طلب التحصيل لقيد مؤرشف من دون تغيير مبلغه أو إعادة فتحه.
2. اختر **متابعة** بجانب الحساب. تعرض الخطة المبالغ التي بقي منها رصيد، وتتيح تسجيل حالة مثل **وعد بالسداد** وملاحظة وموعد متابعة منفصل. يظهر موعد المتابعة الذي حلّ في فلتر **متابعة مستحقة** بحسب يوم الجهاز، ولا يُرسل رسالة أو إشعارًا بمفرده. يمكن فتح الحساب للوصول إلى SMS وواتساب.
3. بعد استلام دفعة، افتح **تسجيل قبض** من خطة اليوم أو كشف الحساب. يُصدر قيد سندًا مرقّمًا ويُسجّل المبلغ كتخفيض لرصيد الحساب في عملته ذاتها. لا ينفّذ التطبيق دفعًا أو تحويلًا ماليًا.
4. زر **أعمار المتأخرات** يبيّن المتبقي المتأخر حسب شرائح **1–30، 31–60، 61–90، وأكثر من 90 يومًا** من تاريخ الاستحقاق. يمكن عرض وتصدير قائمة التحصيل وتقرير المتأخرات إلى **PDF** و**Excel** و**CSV**، مع تطبيق فلاتر الحسابات وبيان العملة وتاريخ التقرير. لا تتضمن التقارير أرقام هواتف العملاء أو ملاحظات المتابعة.
5. **المزيد ← سجل التغييرات** يبيّن آخر **1,000** تغيير مسجّل منذ 1.9، ومنها تغييرات الحركات والحسابات، والاستحقاقات، والإغلاقات واسترجاع التصنيفات. هو سجل محلي محفوظ مع الدفتر، لا سجل تدقيق خارجي أو مقاوم للتعديل. لا يُختلق نشاط سابق عند الاستيراد، ولا تُسجل فيه نصوص الملاحظات أو أرقام الهواتف أو الصور أو مراجع الدفعات.

**طريقة الحساب:** حتى اليوم المحدد، تُخصم السندات المخصّصة من قيودها أولًا، ثم يُوزّع مجموع الدفعات الأخرى على أقدم القيود المتبقية (FIFO)، في الحساب والعملة نفسيهما. تُحتسب الحركات المؤرشفة والتحويلات بطرفها الصحيح. تصنّف التقارير الجزء الذي بقي من القيد؛ حتى في تاريخ سابق، تستخدم المواعيد والتخصيصات المسجّلة حاليًا، وليست نسخة مجمّدة من حالة الدفتر في ذلك التاريخ. لا يغيّر التخصيص أو موعد الاستحقاق صافي الرصيد.

## سندات القبض المرقّمة

1. من **التحصيل ← متابعة ← تسجيل قبض** أو من **كشف الحساب ← تسجيل قبض**، أدخل المبلغ وطريقة القبض: نقدًا، تحويل بنكي، محفظة إلكترونية، شيك، أو أخرى. مرجع الدفعة اختياري ويظهر في السند الفردي. لا يفتح اختيار الطريقة أي تطبيق مالي.
2. اترك **التخصيص تلقائيًا** لتوزيع المبلغ على الأقدم، أو اختر قيدًا موجبًا له متبقٍ. زر **قبض لهذا القيد** في خطة التحصيل يختاره مسبقًا. تتغير القائمة والمتبقي مع تاريخ القبض. لا يقبل السند تاريخًا مستقبليًا، أو مبلغًا أكبر من المتبقي للحساب (أو القيد المخصّص) في ذلك التاريخ. للتسجيل المستقل لدفعة زائدة استخدم **إضافة حركة**؛ لن تصبح سندًا مرقّمًا تلقائيًا.
3. بعد الحفظ راجع السند من **الحركات ← سندات القبض ← عرض السند** أو من تفاصيل الحركة في كشف الحساب. اختر **عرض PDF ← حفظ PDF** أو زر المشاركة، أو **طباعة A4**. الملف يبيّن الحساب والمبلغ والعملة والرقم والتاريخ والطريقة والتخصيص ومرجع الدفعة إن أُدخل، مع موضع للتوقيع. لا يضمّن هاتف العميل أو مذكرة القيد أو صورته. المستند من الدفتر، وليس تأكيدًا من بنك أو فاتورة ضريبية. تُنشأ الملفات محليًا؛ إرسالها إلى طرف آخر يتطلب اختيار المشاركة أو الإرسال صراحةً.
4. في **سندات القبض** اختر العملة ونطاق التاريخ وطريقة القبض، أو ابحث باسم الحساب أو رقم السند. تبقى الإجماليات منفصلة حسب العملة. تصدير السجل إلى **PDF وExcel وCSV** يتبع الفلاتر، من دون مراجع الدفعات أو المرفقات. الحركات السالبة السابقة لا تُرقّم بأثر رجعي.
5. يبقى الرقم ثابتًا عند تعديل السند، ولا يُعاد استخدامه عند حذفه في الدفتر نفسه. حذف السند يحذف قيد القبض ويعيد مبلغَه إلى الرصيد. لا يُعدّل السند المؤرشف ماليًا دون فتح الإغلاق. إذا أردت حذف القيد الذي خُصِّص له قبض، افتح **تفاصيل الحركة ← عرض السندات المخصّصة ← عرض السند ← إلغاء التخصيص** أولًا. يعود السند إلى التوزيع التلقائي بدون تغيير رقمه أو المبلغ أو إغلاق الرصيد.

تحتفظ نسخة قيد برقم آخر سند، ومعلومات السندات وتخصيصاتها، وبالمواعيد والمتابعات وسجل التغييرات. استعد نسخ السندات في **قيد 2.0 أو أحدث**؛ قد تُسقط الإصدارات الأقدم هذه البيانات الإضافية. الترقيم محلي للدفتر، لا للأجهزة مجتمعة. عند استرجاع نسخة أقدم يعود تسلسل السندات إلى آخر رقم فيها؛ احفظ نسخة حديثة قبل استبدال الدفتر.

## إشعار بعد حفظ مبلغ جديد

- بعد **حفظ حركة جديدة** يظهر أسفل شاشة قيد تنبيه لمدة **٣ ثوانٍ** بزرّي **إغلاق** و**إرسال**. الإغلاق أو انتهاء المدة لا يلغي الحركة ولا يفتح تطبيقًا آخر. إن فاتك التنبيه، افتح **تفاصيل الحركة ← مسودة إشعار**. وينطبق الأمر نفسه على حفظ سند قبض جديد. لا يظهر التنبيه بعد تعديل حركة سابقة أو فشل الحفظ.
- يفتح **إرسال** مسودة قابلة للمراجعة، ثم تختار فتح تطبيق SMS أو واتساب. لا يرسل قيد الرسالة بنفسه. من **المزيد ← التفضيلات والأدوات ← الرسائل والتنبيهات** عيّن قناة مفضلة أو اترك اختيارها عند الإرسال. يمكن تعطيل تنبيه الثلاث ثواني؛ أما إشعار أندرويد العام فخيار منفصل لا يكشف المبالغ أو الأسماء.
- يأخذ الإشعار الاسم من **بيانات النشاط ← الاسم أو اسم النشاط**، ثم الاسم بالإنجليزية إن لم يُضبط الأول. يذكر مبلغ القيد واتجاهه بالنسبة للمستلم، والرصيد الإجمالي الحالي في **عملة الحركة نفسها**، بصرف النظر عن فلاتر الكشف. لا يضع تفاصيل الحركة أو صورها في النص. يمكن إدراج التاريخ أو المقدمة والنهاية اختياريًا. في التحويل تختار مستلمًا واحدًا أولًا. مثال:

  > إشعار من مؤسسة المثال:  
  > لك 5,000 محلي واصل  
  > الإجمالي - عليك 28,350 محلي

- إذا لم يجد قيد رقمًا صالحًا، يعرض **اختيار من جهات الاتصال** أو **إضافة جهة اتصال جديدة**، وحقلًا لكتابة الرقم مباشرة. عند إنشاء جهة جديدة في أندرويد، اختر رقمها عند الرجوع إلى قيد. راجع الرقم ثم اضغط **حفظ الرقم ومراجعة الرسالة** لحفظه في الحساب. يقرأ قيد رقم الهاتف الذي اخترته فقط، من دون طلب قراءة أو تعديل دفتر جهات الاتصال. في معاينة المتصفح تتاح الكتابة اليدوية.

## رسائل قصيرة من داخل الحساب

- افتح حساب العميل ثم **خيارات الحساب (⋯) ← إرسال الرصيد** لاختيار **رسالة نصية (SMS)** أو **رسالة واتساب**. تبدأ الرسالة بسطر واحد فيه الرصيد الموقّع والعملة والتاريخ. لا تسرد الحركات ولا تضع ملاحظاتها في الرسالة. يحسب قيد الرصيد من جميع الحركات إلى نهاية الفترة المحددة (أو اليوم إن لم تحدّد نهاية)، حتى لو كان الكشف مفلترًا بالبحث. يمكنك مراجعة النص وتحريره أو نسخه.
- إذا لم تجد رقمًا صالحًا، اختر **إضافة رقم** من المسودة. اختر رقمًا من جهات الاتصال أو اكتبه واحفظه. يضيف قيد رمز الدولة المعيّن في الإعدادات للرقم المحلي. بعد المراجعة اختر فتح SMS أو واتساب، ثم أرسل من التطبيق الآخر. لا يحتاج قيد إذن إرسال SMS ولا يرسل في الخلفية. فتح تطبيقات الإرسال معطّل في بيانات التجربة كي لا تراسل رقمًا بالخطأ.
- من **خيارات الحساب (⋯)**، افتح **SMS + واتساب** للنص نفسه في القناتين؛ تُفتحان كل واحدة بزرها ويجري الإرسال داخل كل تطبيق. أو اختر **مصادقة عبر واتساب** لطلب ردّ يؤكد الرصيد أو يذكر الفرق. نموذج المصادقة المطبوع ما زال متاحًا، ويمكن إبقاء مسودة الكشف الطويلة الاختيارية من إعدادات الإشعارات.

## البحث، Excel وسقف الحساب

- **كشف الحساب ← بحث متقدم:** نص، فترة، نوع الحركة، حد أدنى وأعلى للمقدار دون الإشارة، وإظهار الأرشيف. تبقى إشارة القيد كما هي. يتبع كشف PDF وExcel الفلاتر نفسها؛ يبقى رصيد البداية والنهاية محسوبًا دون فلاتر النص والنوع والمبلغ.
- **التصدير والمشاركة ← حفظ Excel (‎.xlsx)** أو **مشاركة Excel**. الملف مصنف Excel حقيقي من اليمين لليسار، بعناوين ثابتة عند التمرير ومبالغ رقمية موقّعة وثلاث منازل عند الحاجة، وملخص لكل تقرير. بقي CSV متاحًا. الملف المصدّر غير مشفّر، حتى لو كان الدفتر مشفّرًا. الحد 20 ميغابايت للمصنف.
- **خيارات الحساب ← سقف الحساب:** اختر العملة وحدد مبلغًا موجبًا واتجاه الرصيد الذي ترغب في متابعته (**لي** أو **عليّ** أو كلاهما). يظهر استخدام السقف في صفحة الحساب وتحذير داخل قيد عند بلوغه أو تجاوزه أثناء تسجيل الحركة أو التحويل. التحذير لا يمنع الحفظ ولا يغيّر الأرصدة. اترك حقل المبلغ فارغًا لإلغاء سقف هذه العملة فقط. السقوف محفوظة في نسخ قيد؛ استخدم 1.7 أو أحدث للاحتفاظ بها عند الاسترجاع.

## الطباعة الحرارية

من **خيارات الكشف ← طباعة حرارية** اختر **58 مم (384 نقطة)** أو **80 مم (512 أو 576 نقطة)** بحسب مواصفات طابعتك. اختر **إيصال مختصر** للملخص، أو **كشف الحركات المطابقة**. لا تُختصر الحركات تلقائيًا عند تجاوز الطول الآمن؛ استخدم فترة أقصر أو خيار الملخص.

- **طباعة بلوتوث:** اقترن بالطابعة في إعدادات أندرويد أولًا. ثم اضغط **طباعة بلوتوث** واختر الطابعة المقترنة. يتطلب ذلك طابعة **ESC/POS مع Bluetooth Classic SPP** تدعم طباعة الصور النقطية. يطلب قيد إذن الأجهزة القريبة عند الحاجة لهذا الإجراء فقط، ولا يبحث عن أجهزة جديدة. يجهّز قيد العربية كصورة للإيصال، فلا يعتمد على الخط الموجود في الطابعة. رسالة إرسال البيانات لا تؤكّد أن الورق خرج؛ تحقّق من الطابعة قبل تكرار المحاولة.
- **طباعة النظام:** بديل بمقاس 58 أو 80 مم إذا ظهرت الطابعة في خدمة طباعة أندرويد. قد تحتاج إلى تطبيق أو خدمة الشركة المصنّعة. لا يوجد اتصال USB/Wi‑Fi أو BLE مباشر من قيد. الطباعة العادية على A4 مستقلة.

## الخصوصية وحدود التحقق

حسابات الدفتر المحلي محفوظة على الجهاز ولا تحتاج إلى اتصال بالإنترنت. الدفتر المشترك الاختياري يعمل من داخل التطبيق أو من المتصفح عبر HTTPS ويحتفظ بسجلاته على خادمك؛ لا يُفتح عنوانه أو تُرفع نسخة إليه في الخلفية. إذن الشبكة يُستخدم للدفتر المشترك عند فتحه، أو لبدء جلسة الاستعراض المحلية التي تختارها. تُسلَّم الرسائل والملفات إلى تطبيقات النظام فقط عندما تختار ذلك. يمكن قراءة بيانات النسخ غير المشفّرة ببرامج قواعد البيانات، لذلك احتفظ بها في مكان خاص. لا تنشر رابط جلسة الاستعراض ولا ترسل قاعدة بيانات حقيقية لأغراض الاختبار.

تم اختبار الأرصدة والترحيل والتشفير والطباعة في Chromium، وقراءة وكتابة نسخ SQLite والتحقق منها بمحرك SQLite مستقل. اختُبر الترحيل الموجّه على قواعد بيانات وهمية للبنية المرسلة، بما فيها صفوف بمبلغين، وصيغة الإشارة والمقدار، وقيود بلا حساب، ودقة ثلاث منازل، ومطابقة الرصيد وتصدير DB وإعادة استرجاعه. لا تشمل ملفات الاختبار قواعد خاصة. اختُبر مسار Drive بمحاكاة واجهة أندرويد. اختُبر خادم الاستعراض بعملية Java محلية. اختُبر عارض PDF مع صفحات متعددة، والتمرير، والتقريب بالإصبعين والأزرار، والتبديل بين عملات حساب واحد، وملفات التقرير المحفوظة. استُخدمت بيانات وهمية لاختبارات PDF، كما اختُبر العرض المحلي بلا شبكة ووصلة الحفظ/المشاركة بمحاكاة واجهة أندرويد. اختُبرت المسودات والتصدير بوصلة أندرويد محاكية، وفُحص ملف Excel بمحلل مستقل، كما اختُبر إنشاء صورة الإيصال وإطارات ESC/POS ومقاس طباعة النظام. اختُبرت أيضًا مطابقة ذمم التحصيل لأرصدة الكشف، ومعالجة الدفعات الجزئية، والتصدير والتشفير والاسترجاع. اختُبر تنبيه الحركة وحفظ الأرقام عبر محاكاة منتقي أندرويد والكتابة اليدوية. واختُبرت سندات القبض بالتخصيص المباشر والتلقائي، وفشل الحفظ وإعادة المحاولة، والأرشفة والحذف، وملفات PDF والفلاتر واسترجاع سجل السندات من DB مع الحفاظ على الترقيم. واختُبر حفظ تصنيف منفرد واسترجاعه دون تغيير سجلات التصنيفات الأخرى، واستخراجه من نسخة كاملة، والتشفير والتراجع عند فشل الحفظ ومنع تعارض التحويلات. لم تُرسل رسائل فعلية، ولم يُختبر الإصدار على هاتف أو طابعة حرارية حقيقيين.

## تشغيل الشفرة وإعادة البناء

- `app/`: الواجهة ومحرك الحسابات والتشفير. خط IBM Plex Sans Arabic مضمن مع رخصته `app/fonts/OFL.txt`. محرّك PDF وخطوطه محلية وتُحمّل عند فتح العارض؛ تفاصيل الترخيص وإعادة التجميع في `app/pdf/PDF-CREDITS.txt`.
- `android/`: غلاف WebView، حفظ ذري، اختيار الملفات والكاميرا، الطباعة والمشاركة، التنبيهات وجدولة النسخ، وخادم الاستعراض المحلي.
- `shared/`: خادم الدفتر المشترك وواجهة المستخدم وإدارة الصلاحيات. وصفة النشر ودليلها مرفقان، ولا يُضمّن أي ملف قاعدة بيانات أو كلمات سر.
- `tools/`: مصدر قارئ DB المحلي وتجميع sql.js 1.16.0؛ النسخة المجمعة والرخصة مرفقتان في `app/`.
- `tests/`: اختبارات الحسابات والترحيل والتشفير والملفات وسير الاستخدام. تُنشأ ملفات SQLite التجريبية مؤقتًا من Python وتُحذف؛ لا بيانات حقيقية ضمن المصدر.

من مجلد المشروع:

```sh
python3 -m http.server 3000 --directory app
```

ثم افتح `http://localhost:3000`. لتشغيل الاختبارات (Node.js 20 أو أحدث وPython 3 المزود بـ SQLite):

```sh
npm test
npm install
npx playwright install chromium
npm run test:interface
```

اختبار خادم الاستعراض والنسخ وتصدير PDF وExcel وإطارات الإيصال الحراري:

```sh
classes=$(mktemp -d)
javac -encoding UTF-8 -d "$classes" android/src/app/qayd/ledger/LanPreview.java android/src/app/qayd/ledger/BackupInput.java android/src/app/qayd/ledger/PdfExport.java android/src/app/qayd/ledger/ThermalRaster.java android/src/app/qayd/ledger/WorkbookExport.java tests/LanPreviewTest.java tests/BackupInputTest.java tests/PdfExportTest.java tests/AccountAddonsTest.java android/src/app/qayd/ledger/SharedOrigin.java tests/SharedOriginTest.java
java -cp "$classes" app.qayd.ledger.LanPreviewTest
java -cp "$classes" app.qayd.ledger.BackupInputTest
java -cp "$classes" app.qayd.ledger.PdfExportTest
java -cp "$classes" app.qayd.ledger.AccountAddonsTest
java -cp "$classes" app.qayd.ledger.SharedOriginTest
rm -rf "$classes"
```

قارئ SQLite المجمّع في `app/db-engine.js`، ويمكن إعادة توليده عبر `python3 tools/bundle-db.py /path/to/extracted/sql.js-1.16.0/package`. صيغة الحفظ هي SQLite بمعرّف `0x51415944` وإصدار `1`؛ جدول `qayd_backup(part INTEGER PRIMARY KEY, payload BLOB NOT NULL)` يحتوي حمولة UTF-8 أو غلاف Vault مشفرًا، في كتل 65536 بايت. لا تتغير صيغة الحاوية أو مكان الدفتر. محتوى الدفتر بالإصدار 2 يستخدم أجزاء الألف الصحيحة بدل أجزاء المئة؛ يقرأ قيد 1.5 النسخ السابقة JSON وSQLite والمشفّرة دون تغيير قيمها. تحتاج قيم الألف إلى قيد 1.5 أو أحدث، وتحتاج معلومات سندات القبض إلى 2.0 أو أحدث. تستخدم نسخ التصنيفات الحاوية نفسها، ولكن حمولة `qayd-category-backup` بإصدار مستقل تحمي النطاق، ويتطلب استرجاعها قيد 2.1 أو أحدث.

لبناء APK على Linux تحتاج JDK 17 وحزم Android SDK **Platform 35** و**Build Tools 35.0.0** وPython 3 وأمر `zip`:

```sh
export ANDROID_SDK_ROOT=/path/to/android-sdk
export JAVA_HOME=/path/to/jdk17
./build-apk.sh ./Qayd-3.7.apk
```

الحزمة المرفقة موقعة بمفتاح تجريبي؛ المفتاح غير مرفق بالمصدر. للنشر استخدم مفتاحك الخاص من البداية عبر `QAYD_KEYSTORE` و`QAYD_KEY_ALIAS` و`QAYD_STORE_PASS` و`QAYD_KEY_PASS`. لا يقبل أندرويد تحديثًا بمفتاح مختلف. احفظ نسخة من السجلات قبل تبديل توقيع الحزمة.
